VERTEX PRECISION ENGINEERING — ADMIN + CUSTOMER WEBSITE

WHAT THIS PACKAGE DOES
- index.html: public customer website (view only).
- admin.html: password login, upload images/videos, edit captions, delete gallery items.
- Uploaded gallery media is stored online and loaded by the customer page automatically.
- Your logo is embedded in index.html so it does not depend on a missing logo file.

IMPORTANT
This package is prepared but is NOT live or connected until you configure a Supabase project and publish the files on a web host. There is no hard-coded admin password.

SETUP (free tiers may be enough for a small site)
1. Create a Supabase project at https://supabase.com/ and verify your email.
2. In Supabase > SQL Editor, run all of supabase-setup.sql.
3. In Project Settings > API, copy Project URL and the publishable/anon public key. Open supabase-config.js and replace the two placeholder strings. Never use the secret/service_role key in website files.
4. Publish the website files on a static host that supports HTTPS (for example Netlify or Cloudflare Pages). Upload the contents of this folder, keeping index.html, admin.html and supabase-config.js together.
5. Open the deployed /admin.html, create your admin account with your email and a strong password. Complete email verification if prompted.
6. In Supabase > Authentication > Users, copy the UUID for your account. In SQL Editor run: insert into public.admin_users (user_id) values ('YOUR-UUID-HERE');
7. Open /admin.html and log in. Upload a test photo. Open the public homepage in another tab; the photo should appear.

YOUR LINKS AFTER PUBLISHING

- Admin login: https://YOUR-DOMAIN/admin.html (keep this private)

SECURITY
- Only user IDs inserted into admin_users can upload/delete gallery items.
- Customers can view the public gallery but cannot upload/edit it.
- Keep your password private. Do not publish the Supabase service_role/secret key.
- For large videos, use compressed MP4 files; storage and bandwidth limits depend on your hosting plan.

No hosting account has been connected or a public URL created automatically. You must complete the setup and deployment steps to get a shareable live link.
